# jauzey.com

Jekyll site on GitHub Pages (legacy build, branch `master`, CNAME `jauzey.com`). No local build step.

- Posts: `_posts/YYYY-MM-DD-slug.md` with `layout: post` and `title:`.
- Drafts: `_drafts/` is not built by Pages. Move a file to `_posts/` with a date to publish it.
- Collections: `_quotes/`, `_quran/` (pages carry `exclude: true` so they stay out of the nav).
- Style: `css/main.css`, one file, light and dark from the system setting.
